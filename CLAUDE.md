# CLAUDE.md

Project instructions for Claude Code in this repository.

## Writing style

- Never use emojis anywhere: code, comments, commit messages, docs, or chat replies.
- Never use em dashes. Use commas, colons, periods, or parentheses instead.

## Code standards

- Write code that is as efficient as possible: choose appropriate algorithms and data structures, avoid unnecessary allocations, loops, and dependencies.
- Prefer simple, readable solutions when they cost nothing in performance.
- Do not add dependencies unless they are clearly justified.

## Workflow (CI/CD)

1. Code is written in this environment.
2. Changes are committed and pushed to GitHub.
3. Every time new code is created or changed, update `README.md` with the details: what was added, how to use or run it, and any new configuration or dependencies.

## Repository conventions

- Keep `README.md` as the single source of truth for project usage.
- Commit messages: short imperative summary line, then details if needed.
